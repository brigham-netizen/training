How each number is built

  • Each source gives a typical installed range (labor and materials) for one unit, such as a roofing square or a square foot of LVP.
  • Budget uses the low end of each range, Upper uses the high end, and Mid-range uses the midpoint.
  • National sources are multiplied by the Idaho Falls factor. Sources that already price by ZIP code are used as published.
  • The blended rate is the plain average of every source with data. Agent bids join that average when included.
  • The finish level, location factor and agent bids belong to the market, not to a home, so every home in the market is priced the same way. They stay locked until someone unlocks them on purpose.
  • The chip on each line shows how closely the sources agree. Wide spread means the item needs a real bid.
